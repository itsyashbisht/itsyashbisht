## 🚀 Featured Projects

### 🗂️ [IntelliVault](https://github.com/itsyashbisht) — Enterprise RAG Document Intelligence Platform
> Multi-tenant RAG platform with workspace-scoped document isolation and RBAC (Owner / Editor / Viewer) enforced at the API layer.
- 📄 Production ingestion pipeline: unpdf extraction → LangChain recursive chunking → Gemini embeddings → **pgvector HNSW** storage with real-time status tracking
- 💬 Tool-calling RAG chat with **cited source attribution**, token-level streaming, and resumable session history
- 🔐 Email invites (Resend), full audit logging, and enterprise-grade role-based settings

`Next.js 16` `TypeScript` `Drizzle ORM` `Neon (pgvector)` `Clerk` `Groq LLaMA` `Gemini` `Vercel AI SDK v6`

### 🏨 [NestIQ](https://github.com/itsyashbisht) — AI Hotel Booking with Agentic Concierge
> Real-time hotel concierge powered by a multi-turn agentic tool-calling loop on LLaMA 3.3-70B.
- 🔁 `finish_reason` state tracking with branching logic for tool **success, failure, and truncation** scenarios
- 🧩 Structured system-prompt architecture preventing double marker injection — solving a real LLM reliability problem in production agentic flows

`React` `Redux Toolkit` `Node.js` `Express` `MongoDB` `Groq (LLaMA 3.3-70B)` `Tool-Calling`

### 👟 [Solemate](https://github.com/itsyashbisht) — Full-Stack E-Commerce Platform
> Complete e-commerce system: product listings, cart, order workflows, and an admin dashboard.
- 🔐 RBAC (user/admin), JWT auth, bcrypt hashing — strict permission boundaries across the platform
- ⚡ Optimized Redux Toolkit state management eliminating redundant API calls across the purchase funnel

`MERN` `Redux Toolkit` `JWT` `Tailwind CSS`
